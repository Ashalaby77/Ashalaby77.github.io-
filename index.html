About

My career has been about one thing: building models and making them trustworthy. I earned a Ph.D. in ocean engineering, where the real skill wasn't any single topic but a habit — go deep on a hard technical problem, validate it rigorously against real data, then turn what I learned into something others can use.

Over the past year I moved that instinct into applied AI, on purpose. I built a set of production-style GenAI projects on Amazon Bedrock: retrieval-augmented applications, AI agents with tool-calling, MCP servers, and an evaluation harness that scores real model output against a human-validated set. Knowing whether an answer is genuinely good at scale is the hard part most people skip, and it is the part I care about most.

I work across the AI application stack and communicate the same idea to engineers and non-engineers alike: AI you can rely on is grounded in real data, measured honestly, and clear about what it cannot do.

Selected work

RAG

Insurance Claim Processor

A document pipeline on Amazon Bedrock: reads a claim from S3, extracts structured fields with Claude, grounds a coverage decision in policy rules through retrieval, and validates the output. Includes a model-comparison harness proving a smaller model matched a larger one at roughly twice the speed.

AGENT

Grounded AI Agent

An AI agent using Bedrock Converse tool-calling: the model decides which tool to run, looks up real data, and answers only from what came back. Ask about something that isn't in the data and it reports "not found" instead of inventing it — the anti-hallucination discipline production AI needs.

MCP

Model Context Protocol Server

An MCP server exposing data tools through the open protocol, so any compatible AI host can use them without a custom integration. Built on the MCP Python SDK with auto-generated tool schemas, verified in the MCP Inspector and connected live to an AI host. Build the connector once, reuse everywhere.

EVALUATION

LLM-as-a-Judge Harness

An automated evaluation system that runs the real application against a human-validated test set and scores each answer on correctness, groundedness, relevance, and tone, flagging anything below threshold for human review. The capability that tells you whether an AI feature is actually good at scale.
